# Лабораторная работа №2 — Калькулятор калорий и БЖУ

Приложение на **HTML, CSS и JavaScript** для ориентировочного расчёта калорий и БЖУ по параметрам пользователя. Класс `NutritionCalculator` выполняет вычисления, а обработчик кнопки получает данные из формы и выводит результат. Используются формула Миффлина — Сан Жеора и учебные коэффициенты.

## Запуск

Откройте `index.html` в браузере.
